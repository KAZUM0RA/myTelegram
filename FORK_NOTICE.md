# Неофіційний форк

Цей репозиторій — **неофіційна** модифікована збірка клієнта Telegram для
Android, зроблена для особистого/навчального використання.

* Оригінальний код: https://github.com/DrKLO/Telegram
* Ліцензія: **GNU GPL v2 або пізніша** (див. [LICENSE](LICENSE)).
  Похідна робота залишається під GPL, вихідний код відкритий.
* Цей застосунок **не пов'язаний** з Telegram Messenger Inc., не схвалений
  і не підтримується ними.
* Назва «Telegram» та офіційний логотип є торговими марками Telegram
  Messenger Inc. і **не використовуються** в назві застосунку, іконці
  чи package name цієї збірки.
* Збірка використовує власні `api_id`/`api_hash`, отримані на
  https://my.telegram.org, а не облікові дані офіційного клієнта.

## Додані зміни відносно апстріму

| Частина | Опис | Статус |
|---------|------|--------|
| 1 | Підготовка форку, ізоляція секретів | ✅ |
| 2 | Збірка через GitHub Actions, власний package name | ⬜ |
| 3 | Оптимізація WebView для Mini Apps | ⬜ |
| 4 | AI-переклад вихідних повідомлень | ⬜ |
| 5 | AI-переклад вхідних повідомлень | ⬜ |
| 6 | Додаткові AI-функції | ⬜ |
| 7 | Тестування | ⬜ |

AI-функції працюють через Anthropic Claude API. Ключ вводиться
користувачем у налаштуваннях і зберігається лише на пристрої —
у репозиторії та в APK його немає.
